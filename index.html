Browser bugs found along the way

  • Safari (STP 249, WebKit 21626.1.1) one scroll-timeline name shared by many tiles gets slow fast: 1000 tiles block the main thread for 14.5s! (WebKit 322283) Update: fixed in 320902@main.
  • Safari (iOS 18 and later) every carousel is a scroll container, and about 200 of them exhaust the WebContent process. The same phone on iOS 17 rendered 5000. (WebKit 322930) Update: confirmed as an iOS 17 → 18 regression, still open.
  • Safari one scroll-timeline per row drops scrolling to 11 fps, even where every name is unique — so giving each tile its own name buys nothing once the list is long. (WebKit 322931) Update: already fixed in WebKit trunk (WebKit 319589), 59 fps on an iPhone 15.
  • Firefox (156.0a1) animations on translate and scale ignore their animation-range and draw at the wrong point, so the pill breaks up as you scroll. (Mozilla 2006260) Update: fixed for Firefox 159 (Mozilla 2066027).
