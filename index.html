Carousel demos

Scroll-driven page indicators, no JavaScript. Swipe inside any frame — or point at one with a mouse, where a few of them trade the dots for a preview loop instead.

  • base

    Pill glides with the finger. One scroll-driven animation.

  • steps

    Pill jumps dot to dot at the halfway point, via steps() easing.

  • responsive

    Touch: swipe with dots. Pointer: hover previews the first three images.

  • pill-dots

    The active dot is a wide pill. Every dot animates its own width — no overlay.

  • pill-dots-max

    Ten slides, five dots. The strip slides under a fixed window; edges are clipped.

  • pill-dots-max-scale

    Same window, but the outermost dots are half size instead of cut.

  • pill-dots-max-scale-out

    Five equal dots at rest. A shrinking one appears in the margin only mid-swipe.

  • pill-dots-yak

    pill-dots as React components, styled with next-yak. Built output.

  • pill-dots-max-scale-out-yak

    The windowed scale-out indicator as React + next-yak. Built output.

  • content-visibility

    80 tiles of unpredictable height. Toggle containment and watch the page height drift.
